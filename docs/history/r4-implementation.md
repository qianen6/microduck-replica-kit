# Microduck R4 实施方案

更新：2026-09-05。HD-1910-C001 按用户已购处理。本轮核到8个实际商品详情页；整机采购、PCB和3D模型尚未定稿。

## 1. 主控降成本

**优先目标：Radxa ZERO 3W 2GB RAM＋16GB eMMC，带已焊40针排针。**

其次考虑同款2GB、无eMMC版本，另配32GB以上microSD。维持RK3566、ZERO 3W和原有接口方向，不把同名的Orange Pi Zero 3W混进来，也不因便宜直接换ZERO 3E。

- 官方列有1/2/4/8GB内存及多种eMMC配置，统一板框65×30mm。仍需核所发PCB版号、排针、连接器和散热器高度。[Radxa规格](https://docs.radxa.com/en/zero/zero3)
- 本地运行代码采用Rust服务与50Hz控制，策略文件约0.76MB；这不等于总运行内存只有0.76MB。2GB是成本优先的验证目标，不是已经做过整机RAM测试的结论。[项目说明](https://github.com/pollen-robotics/microduck)
- 用精简系统，把训练放在电脑上；在板上验证控制循环、摄像头和音频同时运行的内存及延迟。
- 当前核实的芯板坊商品实选是“单板＋8G/64G”，优惠前1169元、页面显示有货。低配选项存在禁用状态冲突，尚未落实低价供货，因此**不默认采购这块8GB高配板**。
- 主控页：[芯板坊 ZERO 3W](https://item.taobao.com/item.htm?id=746425059858)。此链接未固定高价SKU；目标低配仍需卖家回执。

## 3. 减少自制板和重复采购

首版音频优先采用WM8960成品HAT，替代原AUDIO-HAT-R3自制路线。它有板载双MEMS麦克风、I2S编解码和8Ω负载1W/路输出。采用此路线时取消单独购买CMC-4015-25T及Samtec排母；板载麦克风不接到外部3.5mm插口。[官方功能与接口](https://www.waveshare.com/wiki/WM8960_Audio_HAT)

**该HAT并非已在Radxa上验证即插即用。**官方树莓派安装脚本不直接套到RK3566；需适配音频设备树、I2C/I2S时钟、ALSA设备名，再验证录放音。

配电板仍需定制：舵机TTL、逻辑/舵机分路、欠压、急停默认关闭与手动重使能、回馈尖峰及数字3.3V辅助电源。WM8960板不替代这些保护功能。原34×42mm仅为空间目标，完成电路和布局后再定板框、孔位和PCBA加工资料。

套装8Ω扬声器先作为机外音频调试件；其尺寸尚未核对，不直接当作原来的20mm在机喇叭。

## 4. 已发现并修订的引脚冲突

- WM8960 HAT按钮接树莓派BCM17，即40针**物理11脚**；它与旧方案在11脚上的软件禁能信号冲突。
- 新方案将软件禁能候选移到**物理36脚 / GPIO3_A7**；电路必须在断电或GPIO高阻时保持舵机关闭，最终电平极性由原理图确认。
- **物理13脚预留MCLK**，不再随意占用。HAT有24MHz时钟，完整时钟树仍需驱动验证。
- 音频固定接口：I2C物理3/5；I2S物理12/35/40/38。按选定Radxa内核确认控制器及overlay。
- 躯干IMU仍预留I2C4物理27/28；不进行USB改线。NFC预留UART4、UART5。所有GPIO信号以3.3V为设计基准。
- UART2物理8/10默认兼任控制台，必须处理引导干扰后再接舵机总线。[Radxa引脚与控制台说明](https://docs.radxa.com/en/zero/zero3/hardware-design/hardware-interface)

完整候选针脚分配保存在本轮数据文件中，数字针脚无重复。这是规划检查，不替代接线和实机验证。

## 5. 机械工作已补充的依据

- WM8960官方尺寸图：板框65×30mm，孔距58×23mm；孔径及安装公差另核。
- 已下载[官方3D资料](https://files.waveshare.com/upload/b/b3/WM8960_Audio_HAT_drawing.zip)，解析其中STEP得到外包络 **65.4×31.95×18.9mm**。不要再用1.6mm PCB板厚代表完整板卡总高。
- 相机仍按32×32mm板、28×28mm孔距及真实镜头/FPC座适配。
- 龙邱IMU、优信ToF需各自的载板尺寸；原SparkFun、Pololu安装座尺寸不继续套用。
- 电池实际淘宝型号尚未落实，因此电池托、绑带、插头退出空间不做最终尺寸锁定。
- RA2 Blender及37个原型STL本轮未改动。PR31可和首套原型同批打印，不强制分开下单；整套打印应在同版硬件适配完成后统一安排。

## 6. 现在剩下的具体工作

1. 找到可供的ZERO 3W低配SKU及价格，避免因单个现货结果而默认升到8GB。
2. 落实2S电池、5V模块、在机小扬声器和HD原厂线束/调试器。零搜索结果不视为全淘宝缺货结论。
3. 核IMU/ToF具体载板图、散热总高与紧固件；从最终商品一次收齐资料。
4. 完成WM8960软件适配与定制配电板设计，再统一更新整机模型、线束和开孔。
5. 输出同一版本的最终BOM与整套STL，并做配合、运动和电气测试。
