# R9：按证据取舍的工程评估与模型修订

## 结论与交付状态

已完成数字工程评估，并形成 **R9 工程试装版**。本次修改 11 个现有网格、新增 2 个打印参考件，共 13 个几何对象；原模型保留，当前 Blender 打开修订副本。

这不是整机可靠性认证。模型仍保留 `manufacturing_release=false`、`physical_fit_verified=false`、`electrical_release=false`。相机板厚、紧固件、轴向叠层、真实负载/电流/温升和完整运动范围仍需实测。

## 2. 本次实际完成的修改

### 相机：修正二维尺寸和实际装配通道

- PCB 外形 25×24mm，四孔直径 2mm、孔距 21×12.5mm；顶排孔距板顶 2mm，左右距边 2mm。
- 镜头中心距板底由原先居中假设修正为 **10.25mm**，光轴方向及在头部的 Y/Z 基准保留。
- 板厚 1.2mm 仍是模型假设；镜头整体深度沿用用户给出的 9mm 包络，内部镜片和排线连接器未冒充精细实测模型。
- 新增四孔相机承架，打印孔径 2.4mm，背面名义元件空间 3mm。
- 视觉复核发现下排孔的正面工具通道需要避让，已补 **直径 4.6mm 的螺钉头/工具通道**；四处支撑环及通孔均进行几何检查。
- 沿用旧镜头座与面板的名义连接几何，剔除与新载板无连接的旧 M12 套筒残片。固定座须与真实板厚、焊点、螺钉长度共同试装。

### 电池：保留约束方式，增加可拆后盖

- 保留 19×37×66mm 电池及原托架/绑带约束，不靠新盖板夹紧电芯。
- 新增 2mm 后盖，名义电池后方空隙 **4.5mm**；采用上下安装耳而非最初会侵占髋部空间的侧耳。
- 四处 2.4mm 通孔；安装耳位于电池包上下端之外，检查未侵入名义电池体积。
- 顶部开口 16×8mm，另有可选扎带孔；真实导线直径、弯曲半径和充电插头操作空间仍需试装。接触导线的打印边缘需按实际护套/收口处理。
- 后盖是可拆卸保护件，不是密封壳。紧固件长度、螺母/垫片和充电器与电池化学体系的匹配另行核对。

### 机械件：局部改进，不破坏原安装基准

- 躯干底座及左右 bearing-roll 连接片保留原有轴承座、安装面和孔位，仅在相邻名义包络之外增加材料。
- 新增材料的 0.15mm 避让是数字筛选值，尚未覆盖厂家公差与实际 FDM 误差的完整叠加。
- 左右小腿、左右 yaw2roll 和头部 yaw/roll 共五件，采用 FT 版本的净空切削部分；不增加原先自由空间中的材料。
- 左右上腿加固板继续保持原几何，标注待轴向叠层重设计；左右上腿主体也没有强行移植未经闭合转换及实物叠层核验的凸台。
- 去除面部零件零面积碎片、修复微小接缝；几何简化容差 0.001mm，未把原面板大幅重塑。

## 4. 仍未解决、也没有伪装成已解决的事项

1. **上腿轴向叠层与舵盘实物配合**：需量安装面、舵盘端面、轴承座和螺钉长度；本次保留相关原件并加待复核标记。
2. **完整运动范围**：当前样本包含原机壳已自干涉的姿态，应先确定真实机械限位及可用动作范围，再做连续扫掠与负载验证。
3. **15 舵机供电与通讯**：电池广告 0-3A、OpenRB 端口 3A 不是整机动态余量证明；需要台架记录峰值电流、总线最低电压、温升和保护动作。
4. **实际制造误差**：相机板厚、紧固件、材料牌号、打印方向/层间强度和收缩量均未在本次测得。

建议先打印相机承架和后盖做低成本试装，再做单关节台架。原模型与完整回滚副本均保留。
