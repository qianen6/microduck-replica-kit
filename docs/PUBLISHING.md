## 脱敏边界

- 不直接上传整个工作区，不携带本地 Git 配置、凭据、应用/虚拟环境、下载缓存、日志、设备连接文件、打印机 G-code、商家聊天、订单与个人截图。
- 文字中的本机绝对路径转为公开相对入口或历史资料提示；公开上游署名和链接保留。
- Blender 删除带本机路径/设备字段的自定义元数据、嵌入脚本和无用图像；重开后核对对象网格、变换、父子层级和材质分配不变。
- 3MF 解包检查源路径和连接字段，去掉旧缩略图和切片摘要；3D 成员逐字节核对相同，支撑仍启用。去掉缓存后应重新切片。
- 群二维码按维护者要求作为公开邀请入口保留；只清除 JPEG 元数据，不修改二维码像素流。有效期以 README 和原图为准。
- 扫描涵盖发布树文字、结构化 3MF 内容、Blender 可读字符串、图片元数据和文件名；STL 检查固定格式与标题。启发式扫描不代表任意形式的敏感信息都可自动识别。

## 可复核性

运行 `python tools/verify_publication.py modified` 检查文件清单哈希、39 件 STL 格式、3MF 设置与成员、必要文件和 Markdown 链接。

`proof/source-manifest.json` 记录选入资料的工作区相对来源与原始哈希，不包含原文件内容备份。`proof/blender-sanitization.json` 和 `proof/3mf-sanitization.json` 记录本次结构化核验；`models/r9/evidence` 明确标注为历史数字检查。

`ROLLBACK.sh TARGET_README` 仅把指定 README 副本恢复为发布前版本，不删除当前模型、不改动远端。全仓回退应对发布提交执行常规 Git revert 并另行确认推送。本次仅在独立 README 副本上实测恢复。
