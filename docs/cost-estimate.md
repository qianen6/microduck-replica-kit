# First-prototype cost estimate

Indicative DIY material budget as of the source snapshot date; engineering labor is excluded.

| Category | Range (CNY) |
|---|---:|
| 15 compact smart actuators | 2,800–4,500 |
| Radxa-class compute | 250–450 |
| IMU, MCU, ToF and camera | 400–800 |
| custom PCB, bus and power prototypes | 500–1,500 |
| battery and charger | 150–350 |
| printing | 200–1,200 |
| fasteners, bearings and harness | 300–700 |
| debug adapter | 100–300 |
| rework and spares | 800–1,500 |
| **Total** | **5,500–11,300** |

A practical planning number for the first runnable prototype is approximately CNY 10,000. Outsourced CAD, PCB design, assembly and printing can move the first article above CNY 15,000.
