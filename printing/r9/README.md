# R9 打印文件说明

## 两类文件不要混淆

- `models/r9/stl`：从当前 R9 场景导出的 **39 件**打印对象，毫米单位、零件局部坐标。轴承、舵机和板卡不作为打印件导出。尚需按实际打印机确定方向、材料、支撑和公差。
- 本目录 `R9_11_parts_support.3mf`：既有 **11 件**工程试装排版子集，两盘，不是完整整机套件。第一盘 10 件黑色 PLA（耗材 4），第二盘 1 件浅紫色电池后盖（耗材 3）。P1S / 0.4 mm / 纹理 PEI，100% 尺寸。

## 支撑与脱敏

3MF 保留 `enable_support=1`、`tree(auto)` 和 30° 阈值，保留 3D 网格、变换、材料及盘分配。发布时移除了缩略图/旧切片摘要，并排查连接字段和源路径。Bambu Studio 打开后应重新生成预览、检查朝向、选择本机耗材后重新切片。未包含设备凭据、机器 G-code，也未发送打印任务。

2026-09-14 的本地切片记录有 899 个支撑特征段及 330 个支撑界面段；这是历史单盘记录，不是此公开包的全机时长/重量承诺。本次未重跑切片。

先做相机承架和电池盖试装，核对板厚、焊点、螺钉头及工具通道，再扩展结构件。完整运动范围、电气与实物强度尚未通过验证。
